# 页面音色采集器 Chrome 插件

该插件专门用于采集当前标签页中的音频，并将录到的声音转成 **16 kHz 单声道 WAV**。
采集完成后可以试听、下载，或者保存到 CosyVoice Web 的音色库。

## 功能

- 采集当前标签页音频，提供 5、10、20 秒三档时长。
- 使用 offscreen document 转码，采集期间仍可正常听到页面声音。
- 在插件内试听录音并下载 WAV。
- 可保存为自定义音色；填写参考文本后可同时注册到推理运行时。
- 后端未启动时仍可独立采集和下载，不影响录音功能。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录 `chrome-voice-capture/`。

## 使用

1. 打开正在播放人声的网页。
2. 点击扩展图标，选择采集时长。
3. 点击「开始采集」，首次使用需要授权标签页音频。
4. 采集完成后可试听或下载 WAV。
5. 如需保存到音色库，展开「保存到音色库」，填写名称后提交。

参考文本必须与音频内容一致。只保存样本时可以留空；勾选“注册到推理运行时”后必须填写，
否则后端无法建立音频与文本的对齐关系。

## 后端地址

默认地址为 `http://127.0.0.1:8000/api/v1`，可在扩展设置页修改。

## 检查

```bash
cd chrome-voice-capture
npm run check
```
