# 页面音色识别 Chrome 插件

这是一个无需构建的 Manifest V3 扩展。它通过 `chrome.tabCapture` 采集当前标签页声音，
在 offscreen document 中转成 16 kHz 单声道 WAV，再调用后端：

```text
POST /api/v1/timbre/identify
```

后端提取 campplus 说话人向量，并与 CosyVoice Web 的音色库及可用内置音色做余弦相似度匹配。
没有命中时会继续返回基频、音域、频谱重心等可解释的声学特征。

## 安装

1. 启动 CosyVoice Web 后端，默认地址为 `http://127.0.0.1:8000`。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本目录 `chrome-extension/`。

## 使用

1. 打开正在播放清晰人声的网页。
2. 点击扩展图标，选择采集 5、8 或 12 秒。
3. 点击「开始识别」。首次使用时 Chrome 会要求标签页音频采集授权。
4. 查看音色特征与音色库候选。音色库为空时仍会返回声学特征。

后端地址可以在扩展的「设置」页面修改。默认只预授权本机 `localhost` 与 `127.0.0.1`；
使用其他地址时，保存设置会请求对应的主机访问权限。

## 限制

- 这是本地音色库的声纹相似度匹配，不等同于身份认证。
- 音乐、多人同时说话、强背景噪声会显著降低候选匹配质量。
- 页面必须处于播放状态；静音和极短片段无法得到稳定声纹。
- Chrome 内部页面、扩展商店等受保护页面不允许采集。

## 检查

```bash
cd chrome-extension
npm run check
```
