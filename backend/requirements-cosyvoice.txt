# ===========================================================================
# CosyVoice 推理依赖（本地 / 单机部署用）
#
# 由官方 CosyVoice/requirements.txt 裁剪而来，改动仅有三处，理由如下：
#
#   1. torch / torchaudio 按平台选择版本
#      Intel Mac（darwin + x86_64）上 PyTorch 最后一个可用版本是 2.2.2，
#      2.3.x 起官方已不再发布 macOS x86_64 轮子，装 2.3.1 会直接报
#      "No matching distribution found"。
#
#   2. 移除确实不会进入推理 import 链路的依赖
#        deepspeed            → cosyvoice/bin/train.py、utils/train_utils.py
#        tensorboard          → 训练
#        grpcio* / protobuf   → runtime/python/grpc
#        gradio               → webui.py 与 matcha/app.py
#        tensorrt-*           → 仅 Linux，且 file_utils 内部按需 import
#
#   ⚠️ 踩坑记录：不要凭"看起来像训练依赖"就删包。cosyvoice2.yaml 里包含
#   训练用的 data_pipeline 配置，hyperpyyaml 在**加载模型时**会急切地
#   pydoc.locate() 解析其中每一个 callable，因此下面这些"训练用的"包
#   实际上都是推理加载的必经之路，全部必需：
#        cosyvoice.dataset.processor.*  → pyarrow, pyworld
#        matcha/utils/__init__.py       → rich, lightning, gdown, matplotlib, wget
#        matcha/models/components/*     → conformer, diffusers
#   少任何一个都会在加载模型时抛 ModuleNotFoundError。
#
#   3. 保留 openai-whisper
#      cosyvoice/tokenizer/tokenizer.py 在推理时会 import whisper.tokenizer，
#      因此必须安装。它只提供 sdist，安装时需要约束构建期的 setuptools，
#      请使用 scripts/install_cosyvoice_deps.sh，不要直接 pip install -r。
#
#   4. pyworld 只有源码包，需要本机有 C/C++ 编译器
#      （macOS 执行 xcode-select --install 安装 Command Line Tools 即可），
#      它是 cosyvoice/dataset/processor.py 的顶层 import，加载模型时必经。
#
# 一键安装：
#   bash scripts/install_cosyvoice_deps.sh
# 等价的官方全量依赖（含训练）：
#   pip install -r CosyVoice/requirements.txt
# ===========================================================================
